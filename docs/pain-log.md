# Pain log

Fill this in during the dogfooding week (Days 15-20) and keep it going afterwards. One line per entry, written the moment something annoys you.
The Stage 2 scope is decided from this file, not from assumptions.

| Date | Where (screen / step) | What annoyed me or was missing | Severity (1-3) | Seen again? |
| --- | --- | --- | --- | --- |
| | | | | |

## How to use it

- Severity 3 = I stopped using the app or went back to a spreadsheet because of it.
- When the same thing shows up three times, it becomes a backlog item.
- At the end of the week, write down: the 3 most frequent pains, 3 features I never used, 1 thing I did not expect to need.
